{% load i18n %} {% comment %} Styled clearable file input for an Institution branding image (logo, favicon), laid out as a media row: a thumbnail on the left, actions on the right. Copy comes from the widget's constructor kwargs (see BrandingFileInput), so a second field does not read "Upload logo". data-file-* hooks are scoped inside the data-file-field wrapper; the branding tab's inline script loops over the wrappers rather than querying globally. data-file-current-label carries the alt text for the that script injects when a file is picked on an empty field (the script has no access to widget kwargs). icon_variant switches BOTH the 48px square thumb box and the empty state: an icon tile has no room for a wrapped label, so it renders no inner text and carries role="img" + aria-label instead. The role is not optional -- aria-label is ignored on a bare div's implicit generic role. Note: attrs are inlined (not via {% include "django/forms/widgets/attrs.html" %}) because the TemplatesSetting renderer uses the project template engine, which does not include Django's built-in forms template directory. {% endcomment %}
